# Phase 13 - M3tal Hub Integration

## Goal
Make M3tal-Hub the discovery and presentation layer for the unified repository.

## Tasks
- Define app catalog data.
- Connect Hub entries to package names.
- Display current package versions.
- Display supported platforms.
- Provide installation instructions.
- Link source repositories.
- Link documentation.
- Keep Hub presentation separate from APT repository storage.

## Completion Criteria
- A user can discover a M3tal app in M3tal-Hub and obtain its correct APT installation command.
