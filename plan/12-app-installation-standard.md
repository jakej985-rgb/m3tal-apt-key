# Phase 12 - App Installation Standard

## Goal
Give every M3tal Linux application one consistent installation experience.

## Standard
Install the repository once, then use APT:

`sudo apt install m3tal-<app>`

## Tasks
- Define package naming.
- Define application dependencies.
- Define desktop integration where applicable.
- Define configuration locations.
- Define upgrade behavior.
- Define uninstall behavior.
- Define application documentation requirements.
- Remove project-specific installation workarounds where possible.

## Completion Criteria
- Every supported M3tal Linux application follows the same installation model.
