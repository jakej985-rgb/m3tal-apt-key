# Phase 1 - Repository Standard

## Goal
Define the permanent standard for the unified M3tal Debian repository.

## Tasks
- Define repository URL.
- Define `stable` distribution.
- Define repository components.
- Define supported architectures.
- Define package naming conventions.
- Define package versioning rules.
- Define Debian metadata requirements.
- Define dependency conventions.
- Define supported Debian/Ubuntu releases.
- Document the standard for every M3tal project.

## Deliverables
- `docs/repository-spec.md`

## Completion Criteria
- A new M3tal project can follow one documented package standard.
