# Phase 8 - Versioning

## Goal
Establish predictable independent versioning for every M3tal package.

## Tasks
- Use independent package versions.
- Define semantic versioning rules where appropriate.
- Define Debian revision handling.
- Prevent publishing an older version over a newer version.
- Define prerelease behavior.
- Define package retirement behavior.
- Document upgrade and downgrade expectations.

## Completion Criteria
- APT can correctly determine upgrades for every M3tal package.
- Package releases do not require unrelated projects to release simultaneously.
