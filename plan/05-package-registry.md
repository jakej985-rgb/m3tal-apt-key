# Phase 5 - Package Registry

## Goal
Create a machine-readable registry connecting M3tal projects to published packages.

## Tasks
- Create a package registry.
- Record package name.
- Record source GitHub repository.
- Record package type.
- Record supported architectures.
- Record publication settings.
- Record dependencies where needed.
- Define registry validation rules.

## Deliverables
- `registry/packages.yml`

## Completion Criteria
- Every published M3tal package has one authoritative registry entry.
